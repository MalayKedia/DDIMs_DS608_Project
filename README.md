# Denoising Diffusion Implicit Models (DDIMs)

Course presentation for **DS 608**, IIT Bombay (Spring 2026).

**Presenter:** Malay Kedia  
Based on Song, Meng & Ermon, *Denoising Diffusion Implicit Models* (ICLR 2021).

DDIMs accelerate sampling from a pretrained DDPM by using a non-Markovian forward process with the same marginals, enabling fewer reverse steps and optional deterministic sampling.
